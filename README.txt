공부 캘린더 설치 안내

1. 압축을 풀면 index.html, manifest.webmanifest, sw.js, 아이콘 파일이 있습니다.
2. PWA 설치(홈 화면 앱처럼 사용)를 하려면 이 폴더 전체를 HTTPS로 제공해야 합니다.
   가장 쉬운 방법 중 하나는 GitHub 저장소를 만든 뒤 파일 5개를 올리고
   Settings > Pages에서 배포하는 것입니다.
3. 배포된 https://... 주소를 갤럭시에서 Chrome 또는 Samsung Internet으로 엽니다.
   브라우저 메뉴에서 '홈 화면에 추가' 또는 '앱 설치'를 선택합니다.
4. 입력 내용은 해당 기기/브라우저의 로컬 저장소에 보관됩니다. 다른 기기와 자동 동기화되지 않습니다.

기능
- 월간 달력 및 날짜별 공부 과목/시험 메모
- 과목 추가/삭제, 과목별 시험일 설정
- 단원 추가/완료 체크/삭제, 과목별 진도율
- 과목별 D-day 표시(D-5, D-DAY, D+N)
- 남은 단원 수와 시험일까지 남은 기간의 비율을 반영해 긴급도가 높은 과목부터 배치하는 계획 생성(단원당 2시간)
- 홈 화면 설치 후 standalone 형태로 실행, 오프라인 캐시 지원

참고
- 계획 생성기는 현재 미완료 단원을 시험일이 빠른 과목부터 배치하는 기본 버전입니다.
- 이미 지난 시험일의 미완료 단원은 일정에서 제외될 수 있습니다.
- 데이터는 브라우저 데이터 삭제 시 사라질 수 있으므로 중요한 기록은 주기적으로 백업하세요.
